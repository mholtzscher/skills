# Encode lessons

When the same correction recurs, fix the cause at the strongest useful level: architecture, types, validation, lint, tests, then guidance. Build a reusable helper when repeated mechanics or reliable proof justify one.

A script is valuable when a reviewer can rerun it and observe the same contract. Do not turn every one-off edit into a framework. Propose changes to shared skills as their own scoped work; discovering a workflow defect does not authorize modifying the user's global installation.
